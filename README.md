# urmamge.github.io

My personal website, live at [matthewhearst.com](https://matthewhearst.com). It has my portfolio and a page for each thing I've made, like my bots, plugins and apps.

Built with Vite, React, TypeScript and [Mantine](https://mantine.dev).

## Some pages

| Page | What's on it |
| --- | --- |
| `/portfolio/` | Main page: about me, my projects and socials |
| `/urmamge/` | The "online" version of my portfolio, focused on my online life |
| `/repos/` | My GitHub repos |
| `/calorietracker/` | Personal website to track my calorie history remotely |
| `/bots/overwatchbot/` | Overwatch Bot, a Discord bot for Overwatch patch notes |
| `/plugins/spotifyoverlay/` | Spotify Now Playing, an OBS plugin that shows the song playing in Spotify |
| `/plugins/beatmarker/` | DaVinci Beat Marker, a DaVinci Resolve plugin that puts beat and bar markers on your song clip |
| `/apps/doctoaudio/` | Doc to Audio, which turns a PDF, Word, text or Markdown file into an MP3 from the right-click menu |
| `/youdiedmc/` | A Minecraft death screen with "respawn" buttons to the main pages |
